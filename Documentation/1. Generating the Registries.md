## Step 1 - Downloading the original server

Download the Minecraft Server via Minecraft Launcher:
1. Navigate to Installations
2. Press `New Installation`
3. Locate version 1.21.10 and press Install
4. Press the hamburger button on the 1.21.10 install (the `...` button), and then Edit
5. There you have a button on the right side called `SERVER`, press it
6. Save the server jar file somewhere on your PC, best to have it in its own folder

## Step 2 - Generating JSON dump

Open your terminal app, either cmd or powershell, then locate your server jar file. Next, paste this command:
```Shell
java -jar server.jar --bundlerRepoDir . nogui
```

Right after it executes, paste another command and run it:

```shell
java "-DbundlerMainClass=net.minecraft.data.Main" -jar server.jar --all --output generated
```

This will create a new folder called `generated`. Entire JSON dump for NBT data is over there. Do not remove or edit anything.

## Step 3 - Run FunCraft.RegistryBuilder

Build the `FunCraft.RegistryBuilder` independently on either Debug or Release build, locate it and copy over to the main directory with the server jar file, next create folder called `output`.

Now, in your terminal app paste and run this command:
```
.\FunCraft.RegistryBuilder.exe .\generated .\output\registries.bin
```

## Step 4 - Copying the registeries

Now copy the `.\output\registries.bin` into project's `FunCraft.Protocol\Resources` folder. Next, in the visual studio locate the resource manager of `FunCraft.Protocol` project.

Remove the entry and add it again as file. It will add it as `byte[]`. That's expected and it should work as intended.
